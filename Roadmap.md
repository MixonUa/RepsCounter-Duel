# Roadmap — план разработки Reps Counter

> Поэтапный план. Требования — в `CLAUDE.md`, текущее состояние кода — в `ProjectTree.md`.
> Экраны взяты из описания макета Figma (2026-11-19); доступ Figma MCP к файлу пока не получен, точные размеры и цвета будут сверены позже.
> Статусы: ✅ готово · 🚧 в работе · 📋 запланировано

**Последнее обновление:** 2026-11-19 — этап 0: пакет, каркас и экраны на тестовых данных готовы; токены дизайна временные до доступа к Figma MCP.

## Принятые решения по макету (2026-11-19)
- Везде одна сумма повторений из дуэлей (приседания + отжимания), без разделения по упражнениям; тренировки не учитываются.
- Без разрешения камеры в приложение не пускаем (экран «подсказки по камере» + «Open Settings»). Риск App Review 5.1.1 — перепроверить перед релизом.
- В карточке найденного игрока виден список его друзей.
- Выбор мотивации в онбординге — только для вовлечения, на сервер не сохраняется.
- Входящая заявка в друзья: всплывающий экран (Accept / Decline / ✕); после ✕ — плашка сверху на всех табах до ответа.

## Этапы

### Этап 0. Фундамент 🚧 (каркас готов; ждёт токенов из Figma)
- Локальный Swift-пакет: `DesignSystem`, `ExerciseAnalyzer`, `Backend`.
- Каркас приложения: свой таббар Home / Rating / Profile + отдельная кнопка Duel, навигация, mock-данные.
- Liquid Glass на iOS 26+ и фолбэк для iOS 18–25.
- `supabase-swift` (закреплённая версия), dev-проект Supabase — только по команде.
- Токены дизайна — после получения доступа к Figma MCP; до этого системные значения.

### Этап 0.5. Прототип распознавания позы 📋 (параллельно с этапом 1)
- Vision → точки тела → скелет поверх камеры → черновой подсчёт приседаний и отжиманий спереди.
- Проверка на реальном iPhone: особенно отжимания с фронтальной камеры.

### Этап 1. Онбординг и регистрация 📋
- 2 слайда → ник → эмодзи → подтверждение → мотивация → 3 слайда → разрешение камеры / подсказки по камере.
- Сервер: анонимная сессия, `profiles`, уникальный ник без учёта регистра, лимит регистраций, RLS.
- Определение новой установки, очистка старой сессии в Keychain.
- Тесты: ник занят, нет сети, переустановка.

### Этап 2. Профиль и друзья 📋
- Profile: иконка, ник, компактная статистика, топ-3 друзей, See all, Add friend (пустое состояние — только Add friend).
- Add friend: поиск по точному нику → карточка игрока (статистика, его друзья, «Add to friends»).
- Входящая заявка: всплывающий экран + плашка на всех табах.
- Сервер: `friend_requests`, `friendships`, RLS, тесты чужого доступа и дублей.

### Этап 3. Тренировка 📋
- CameraService, PoseDetection, `ExerciseAnalyzer` (машины состояний + юнит-тесты на синтетике).
- Настройка → калибровка → тренировка → результат; рекорд в SwiftData + фоновая синхронизация.
- Home: кнопка «Start training», блок рекорда.

### Этап 4. Дуэль 📋
- Настройка (упражнение, 30/60/90 с) → приглашение друга → лобби готовности → отсчёт → дуэль → результат.
- Входящее приглашение у соперника (дизайна пока нет — временный вариант).
- Сервер: `duel_invitations`, `duels`, `duel_participants`, `duel_rep_events`, машина состояний, атомарная финализация.
- Переподключение (10 с), выход, ничья, истечение приглашения.

### Этап 5. Статистика и рейтинг 📋
- Сервер: дневная статистика дуэлей, `leaderboard_totals` (одна сумма).
- Home: график по дням, Recent Duels (последняя дуэль или «Challenge»), текущее место в рейтинге.
- Rating: Global / Friends, пагинация, одинаковое место при равных суммах.

### Этап 6. Релиз 📋
- Визуальная сверка с Figma на iOS 18 и 26, Dynamic Type, VoiceOver.
- Push-уведомления (нужен платный Apple Developer Program).
- `PrivacyInfo.xcprivacy`, политика конфиденциальности, тесты на устройствах, prod-проект Supabase.

## Отложенные вопросы
- Входящее приглашение в дуэль у соперника, ошибки регистрации, состояния переподключения/спора в дуэли, удаление и блокировка друзей.
- Рекорд тренировки: один или по упражнению, зависит ли от длительности.
